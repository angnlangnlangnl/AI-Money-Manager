一、RSI网格策略

触发条件：
- RSI < 30（超卖）→ 买入
- RSI > 70（超买）→ 卖出
- 30 ≤ RSI ≤ 70 → 持有不动

参数设置：
- RSI周期：14
- 超卖阈值：30
- 超买阈值：70
- 网格间距：2-3%

优点：过滤震荡噪音，只在极端点位操作
缺点：可能错过趋势行情

二、布林带网格策略

触发条件：
- 价格触及下轨 → 买入
- 价格触及上轨 → 卖出
- 价格回归中轨 → 平仓

参数设置：
- 布林带周期：20
- 标准差倍数：2
- 网格间距：1-2%

优点：统计学基础，适合均值回归
缺点：单边趋势中可能连续止损

三、EMA趋势网格策略

核心逻辑：
- EMA20 > EMA50 → 只做多（金叉买入，回调加仓）
- EMA20 < EMA50 → 只做空（死叉卖出，反弹减仓）
- EMA20 ≈ EMA50 → 纯网格（高抛低吸）

参数设置：
- EMA短期：20
- EMA长期：50
- 网格间距：1.5-3%
- 仓位管理：每格10-20%

止损条件：
- 价格跌破网格下限5%
- 或趋势反转（EMA死叉）

四、KDJ网格策略

信号判断：
- K线从下方穿越D线（金叉）→ 买入
- K线从上方穿越D线（死叉）→ 卖出
- J值 > 90 → 超买减仓
- J值 < 10 → 超卖加仓

参数设置：
- KDJ参数：9,3,3
- 网格间距：2%
- 单格仓位：5-10%

五、MACD网格策略

信号判断：
- MACD金叉 → 开启做多网格
- MACD死叉 → 开启做空网格
- MACD柱状图缩量 → 网格间距收窄

参数设置：
- MACD参数：12,26,9
- 网格间距：动态1-3%

六、多周期网格策略

核心逻辑：
- 4小时级别判断趋势方向
- 1小时级别确定网格区间
- 15分钟级别执行网格交易

执行规则：
- 4H趋势向上 → 只做多网格
- 4H趋势向下 → 只做空网格
- 4H震荡 → 双向网格

七、风控规则

止损规则：
- 硬止损：单格亏损超过5%强制平仓
- 总止损：账户回撤超过15%停止策略

仓位管理：
- 单格仓位：总资金的5-10%
- 最大持仓：不超过总资金的60%
最优策略推荐：EMA趋势过滤 + 动态ATR网格 + RSI辅助确认

核心要素：趋势过滤、动态间距、风控止损、仓位管理、信号过滤
